## 로컬에서 열기

정적 HTML 실습입니다. 저장소 루트에서 Python 3의 로컬 서버를 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속합니다.
외부 API를 사용하는 페이지는 별도 설정이나 서비스 상태에 따라 다르게 동작할 수 있습니다.
이번 문서 정리에서는 모든 페이지와 GitHub Pages 배포 상태를 검증하지 않았습니다.
